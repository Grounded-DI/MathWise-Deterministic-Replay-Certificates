# Two-block Benjamini-Hochberg counterexample

Source: https://github.com/Grounded-DI/MathWise_BH_Two_Block_Counterexample/tree/cd80c4b2f0e18034c28375a179eaf81202e99439

The July 15, 2026 technical note records a fixed two-block, one-factor Gaussian construction in which ordinary Benjamini-Hochberg FDR control exceeds its nominal level under correlated two-sided tests. It reports a lower bound above 0.01 at alpha=0.01 and a fixed-alpha interval result over [0.00998,0.01002].

Classification: fixed-model numerical certificate and technical note. The October MPFR extension is indexed separately.
